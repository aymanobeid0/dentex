# 01: تسجيل المريض بترقيم مستقل ونقل الأرقام الموجودة بأمان

**What to build:** يحصل المريض على رقم من تسلسل عيادته وحدها، ويظهر الرقم المؤكد في الملف والقائمة والبحث. تنتقل الملفات الموجودة إلى ترقيم يبدأ من١ داخل كل عيادة، مع حفظ هويتها وحقولها وروابطها وسجل تحويل أرقامها السابقة.

**Blocked by:** لا شيء؛ متاحة اعتمادياً عند التكليف بالتنفيذ.

**Status:** closed

**Execution:** complete

- [x] لكل عيادة عدّاد تملكه وحدة المرضى، ويبدأ من١ افتراضيًا. تهيئته عند إنشاء العيادة تتم ذريًا مع العيادة والأدوار والمدير عبر الواجهة المعلنة المعتمدة، دون كشف مستودعات أو تغيير مدير المعاملات العام.
- [x] تخصيص الرقم وإدخال المريض في معاملة واحدة، مع تفرد وتزايد داخل العيادة واستقلالها عن التسجيلات في العيادات الأخرى. لا تخصيص بأكبر رقم عند كل تسجيل أو قفل عام يجمع العيادات.
- [x] يبقى الرقم نصًا في عقد التبادل دون فقد دقة. بلوغ نهاية السعة يرفض التسجيل بخطأ معروف دون تكرار أو التفاف، مع بقاء المسودة ودون إعادة إرسال تلقائية.
- [x] إعادة ترقيم الملفات القائمة مرة واحدة من١ لكل عيادة حسب الرقم القديم تصاعديًا، مع حفظ معرّفاتها وحقولها الأخرى وأعدادها وروابطها. يشمل تهيئة العيادات الخالية من المرضى، والتحقق من صحة الرقم التالي لكل عيادة.
- [x] إنشاء سجل تحويل لكل ملف قائم يربط رقمه القديم بمعرّفه الثابت داخل عيادته. يبقى ما دام الملف موجودًا ولا يكشف للأدوار غير المخولة. واجهة المراجعة الفردية في التذكرة03؛ لا تُفقد الخريطة أثناء انتظارها.
- [x] معاينة الانتقال أولًا، ثم إيقاف جميع الكتابات ذات الصلة والنسخ المتصلة، وأخذ نسخة احتياطية نهائية وكشف تحويل بعد الإيقاف وقبل التغيير. تحفظ الملفات خارج المستودع وبوصول محدود، دون بيانات مرضى في الأدلة العامة.
- [x] إثبات قابلية الاسترجاع في بيئة معزولة قبل التنفيذ؛ عند فشل النسخ أو التحقق يتوقف الانتقال. لا إعادة تهيئة للقاعدة أو حذف بياناتها أو تخزينها الدائم، ولا إعادة إنشاء للحسابات أو تغيير كلمات مرور وصلاحيات.
- [x] ترحيل ذري يعالج تصادم الأرقام الوسيطة دون كشفها للمستخدمين، ويلغي المولّد العام. يرفض إعادة التحويل غير المقصودة، ولا تسمح نسخة قديمة بإعادة تخصيص أرقام عامة.
- [x] التحقق من الأعداد والمعرّفات والحقول والخريطة والأرقام والعدادات قبل استئناف الكتابة، ثم تشغيل النسخة الجديدة وإعادة تحميل الواجهات لإزالة ذاكرة الأرقام السابقة. التراجع بعد وصول تسجيلات جديدة لا يستعيد نسخة قديمة بما يحذفها.
- [x] تسجيل وقراءة وبحث فعلي بالأرقام الجديدة باللغتين، مع حفظ سلوك المسودة وتأكيد الخادم والصلاحيات القائم. الفجوات مسموحة، ولا إعادة استخدام بعد الأرشفة أو تصفير سنوي.
- [x] اختبارات من الواجهة والطلبات والترحيل على قاعدة اختبار معزولة: استقلال عيادتين وتسجيلات متزامنة، انتقال بيانات مصطنعة وخريطة كاملة وثبات المعرّفات والحقول، العيادات الخالية، نفاد السعة، ورفض الترحيل المكرر. اختبار تراجع فعلي يثبت رجوع العدّاد مع إنشاء العيادة عند فشل خطوة متأخرة.
- [x] إكمال [معايير الإغلاق المشتركة](../map.md#معايير-الإغلاق-المشتركة)، وتوثيق نتائج هذه الشريحة وحدودها دون تأجيلها للتذاكر التالية.
