# 02: اختيار بداية ترقيم العيادة عند إنشائها

**What to build:** يحدد مدير البرنامج بداية ترقيم ملفات عيادة جديدة عند إنشائها، أو يتركها١؛ يحصل أول مريض على البداية المختارة ثم يستمر تسلسل العيادة مستقلًا.

**Blocked by:** 01 — تسجيل المريض بترقيم مستقل ونقل الأرقام الموجودة بأمان.

**Status:** closed

**Execution:** complete

- [x] حقل بداية واضح في نموذج إنشاء العيادة لمدير البرنامج، افتراضيه١، مع تسميات وتحقق ورسائل بالعربية والفرنسية واتجاهيهما.
- [x] يقبل عددًا صحيحًا موجبًا ضمن سعة أرقام الملفات، ويرفض الصفر والسالب والكسور والقيم غير الصالحة والخارجة عن السعة. لا فقد دقة للأرقام الكبيرة في الواجهة أو العقد أو التخزين.
- [x] يتوافق عقد الإنشاء مع الخطة المعتمدة: الحقل اختياري، وغيابه يعني١، وتستمر الاستجابة القائمة دون كسرها. مصدر الصلاحية هو الخادم؛ غير مدير البرنامج لا يضبط البداية.
- [x] حفظ البداية وتهيئة العدّاد مع العيادة والأدوار والمدير في معاملة واحدة؛ لا إعداد جزئي أو عدّاد يتيم بعد فشل الإنشاء.
- [x] أول تسجيل فعلي يأخذ البداية المختارة، والتسجيلات اللاحقة تزداد من عدّاد العيادة وحدها. لا تغيير لأرقام العيادات القائمة أو إعادة ترقيم ثانية أو تعيين أرقام فردية.
- [x] الضبط ضمن إنشاء العيادة فقط؛ لا شاشة لتعديل البداية لاحقًا أو إعادة ضبط بعد أول مريض، ولا بادئات أو تصفير سنوي أو تنفيذ فواتير.
- [x] تحقق كامل من إنشاء العيادة عبر الواجهة حتى تسجيل أول مريض وفتح ملفه، لبداية افتراضية ومخصصة ولعيادتين. اختبار القيم الحدية والعزل ورفض غير المخول وتراجع الإنشاء الفعلي.
- [x] تحقق لوحة المفاتيح والتركيز واللغتين والاتجاهين باستخدام مكونات الواجهة المعتمدة، دون إعادة تصميم أو مسح المسودة عند فشل الحفظ.
- [x] إكمال [معايير الإغلاق المشتركة](../map.md#معايير-الإغلاق-المشتركة)، مع أدلة مستقلة لهذه الشريحة.
