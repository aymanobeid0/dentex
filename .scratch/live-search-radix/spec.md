# البحث المباشر واعتماد Radix Primitives

Status: ready-for-agent

اعتمد المستخدم في 2026-11-04 بعد المناقشة تحديث نتائج البحث في الجدول، وانتظار 300ms بعد آخر كتابة، واعتماد Radix Primitives للمكونات القديمة والحالية والمستقبلية. التنفيذ باستخدام implement؛ لا إعادة تصميم أو تغيير معماري للخادم أو عقود API.

## عقد السلوك

- تحميل القائمة الأولية مباشرة؛ بعد تغيير نص البحث يُرسل الطلب بعد 300ms من آخر تغيير فعلي للنص المقصوص، من أول حرف، إلى GET القائمة القائم.
- الكتابة تظل متاحة أثناء الانتظار والطلب. تلغى مؤقتات الطلبات السابقة وطلباتها، وتمنع استجابة متأخرة من استبدال نتائج أو أخطاء البحث الأحدث، حتى إذا تجاهل النقل الإلغاء.
- تعرض النتائج في الجدول الحالي؛ لا combobox اقتراحات أو وظائف جديدة. يبدأ النص الجديد من الصفحة الأولى. زر بحث وEnter ينفذان فورًا دون طلب مكرر بعد المؤقت؛ مسح البحث يعيد القائمة فورًا. الصفحات وإعادة المحاولة فوريتان وتتبعان البحث المعروض.
- لا ترسل طلبات وسط تركيب النص بـIME. يبقى التركيز في الحقل عند تحديث النتائج. تُعلن حالة التحميل ونتيجة البحث وعدد العناصر المعروضة لقارئ الشاشة دون ادعاء معرفة العدد الكلي.
- تبقى الأخطاء والصلاحيات والعزل ونطاق اللغة العربية/الفرنسية كما في docs/ui-contract.md؛ فشل الطلب ليس قائمة فارغة ناجحة.

## اعتماد Radix العام

تعتمد الواجهة Primitives غير المنسقة مع التصميم الحالي. تُنقل جميع الأنماط القائمة التي لها بديل مناسب: Label للحقول في الدخول وإنشاء العيادة والحسابات والموظفين والمرضى والبحث؛ Checkbox لاختيارات الطفل والأدوار والمنح؛ Select للجنس؛ Toggle لإظهار كلمة المرور؛ ToggleGroup لاختيار الدور؛ Collapsible للطي الحالي؛ Tooltip للتلميحات؛ Direction Provider للاتجاه وVisuallyHidden للنصوص المساعدة. تبقى الحقول والأزرار والروابط والجداول عناصر HTML أصلية لأن Primitives لا توفر بديلًا لها، ولا تُنشأ نوافذ أو قوائم لم تكن في المنتج لمجرد استعمال المكتبة.

قاعدة المستقبل توثق في AGENTS.md وdocs/ui-primitives.md وDESIGN.md: استخدام primitives المناسبة بدل إعادة صنع التفاعلات وARIA، مع بقاء اختبارات الوصول واللغتين والتصميم إلزامية. لا يعني ذلك ضمان الوصول بمجرد تثبيت المكتبة.

## التحقق والحدود

اختبارات سلوك الواجهة مع مؤقتات مضبوطة للانتظار والإلغاء وترتيب الردود وIME، واختبارات لوحة مفاتيح فعلية للمكونات، والحفاظ على اختبارات HTTP الحالية. البناء والمعمارية وكامل الاختبارات على dentex_test المعزولة، ومراجعتا code-review مقابل main المجلوب حديثًا. تحقق متصفح بالشاشات الحالية والعربية والفرنسية والمكتب والهاتف، وتوثيق أي تعذر دون ادعاء. مراجع التصميم: login-preview.html وDESIGN.md وsource/{Patients,Forms,Dropdown,Settings,Sidebar}.dc.html والعقد الحالي.

لا تسجيل تجريبي على dentex_dev، ولا إعادة تهيئة أو كلمات مرور أو صلاحيات أو موديولات خادم جديدة. تظل بيئة المستخدم شغالة للفحص قبل PR. لا رفع أو نشر أو دمج. ملاحظات الواجهة العامة غير المرتبطة مؤجلة.
