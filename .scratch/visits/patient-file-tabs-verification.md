2026-11-14. توجيه المستخدم: بطاقة المريض ومعلوماته أعلى الملف، ثم تبويبات الزيارات والمواعيد والمخطط السني وخطة العلاج. سُجل قبل التصحيح فيDESIGN وعقدالشاشات ومعمارية الواجهة ومراجعUI. لا وظائف طبية أو بيانات مصطنعة في المنتج؛ يوضح تبويبا المخطط والخطة عدم توفرهما الحالي.

## السلوك والملكية

أضيفتTabs المشتركة عبر@radix-ui/react-tabs1.1.22، ومظهرui-tabs-* فيprimitives.css. تملكpatients اختيار القسم وتبقي البطاقة فوقه، وتبقى فتحات الميزات وتركيبapp. يمر تبديل القسم عبرonSectionChangeRequest وحراس الزيارات والمواعيد والصفحة قبل إزالة القسم. يمنع طلب انتقال معلق تكرار طلب الحراسة منfocus/mousedown؛ خيارالبقاء يعيد السماح بمحاولة لاحقة. يزيلRadix محتوى التبويب غير النشط، فتتوقف قراءاته دون مديرcache جديد أوطلبات أعمال فيapp.

## الاختبارات الجزئية

أثبت الاختبار الأول فشل3حالات لغيابtablist، ثم نجحت حالتاAR/FR وبقيت حالة الحراسة حمراء بسبب طلبها مرتين. صُحح الانتقال المعلق، ونجحت3/3، ثم أُثبت البقاء وإعادة المحاولة ضمن حالة الحراسة. اجتازت المجموعة المتأثرة لتبويبات الملف وتعديل/أرشفة/بحث المرضى **36/36 في4ملفات** دون تخطٍّ؛ التقرير الخارجيpatient-tabs-partial.json. لاfull suite لهذه الشريحة وفق[ADR0005](../../docs/adr/0005-feature-completion-full-suite.md). فحص الأنماط ناجح وdiff-check بلا أخطاء بعد تنسيقEOF؛ البناء والأنواع تحققا مع03.
