# 05 والتكامل النهائي — مراجعة مستقلة

جُلب main حديثًا وثُبت `3dfb963e72871e7103ce3d863124e82ac7661ac6`. راجع مراجعان بسياق جديد جميع01–05: `git diff <baseline>...HEAD` للسياق المحفوظ، و`git diff HEAD` وكل ملفات05 الجديدة، بما فيها الترحيل والعامل واختبارات HTTP والواجهة والتخزين. بقيت المسارات المستثناة خارج القراءة. فُتحت صورتا Patient المرجعيتان. هذه مراجعة قراءة فقط ولا تثبت تشغيل اختبارات أو قبولًا بشريًا.

## Standards

سجل `/root/review_final_standards` ملاحظةP2 واحدة: تتدارك الخدمة اليوم في معاملة مستقلة، لكن قفل المعاملة البشرية قد يُكتسب بعد منتصف الليل دون فحص تغير اليوم؛ عندها يمكن بدء انتظار الأمس أو إنهاء زيارته كعملية عادية. يلزم تحرير القفل دون كتابة بشرية، والتدارك المستقل ثم إعادة القفل والتفويض والإصدار. لم يجد خرقًا إضافيًا للطبقات أو الملكية أو الواجهات أو Query أو Radix أو أنماطها المشتركة.

## Spec

سجل `/root/review_final_spec` ملاحظتيP2: سباق منتصف الليل نفسه، وعرض `auto_closed` في ملخص مراجعة تعارض VisitsPage بوصفه مغادرة قبل الدخول أو زيارة مكتملة، بما يخالف الحالة المستقلة المعتمدة. لم يثبت نقصًا آخر أو توسع نطاق. لا تُجمع الملاحظة المشتركة مرتين بوصفها عيبين مختلفين.

## التصحيح والتحقق اللاحق

أُسند التصحيح إلى منفذ جديد واحد `/root/fix_visits_integration` مع اختبارات أحمر ثم أخضر. أضيفت له ملاحظة بصرية من الوكيل الرئيسي: استخدام حقل السبب للتنسيق المشترك `ui-textarea` بدل حقل HTML الخام، دون CSS override أو تغيير معماري. [دليل الإصلاحات](integration-fixes.md) مصدر نتائج التشغيل؛ تُسجل مراجعة delta النهائية هنا عند اكتمالها. المجموعة الشاملة تنتظر استقرار هذه الإصلاحات وفق ADR0005، ولا نجاح نهائي مفترض.

أعاد المراجعان قراءة delta وأكدا **Standards0 / Spec0 متبقية**: فحص اليوم تحت القفل وإعادة التدارك المستقل، وتسميات الحالات الكاملة، دون تغيير معماري. صُححت لاحقًا تهيئة اختباري قائمة انتظار الأقفال فقط بعد كشفها في أول full suite؛ لا تغيير إنتاج أو تقليل ضمانات أو توسيع مهل. نتيجة التشغيل الشامل النهائية في [دليل التكامل](integration-verification.md).
