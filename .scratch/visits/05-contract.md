# 05 — عقد الإغلاق اليومي قبل الكود

2026-11-14. ينفذ [العقد المعتمد صراحة](02-05-contract-proposal.md) والمواصفة دون توسعة معمارية. نقاط الاختبار المعتمدة: HTTP مع PostgreSQL مصطنعة معزولة، وسلوك UI وسلسلة UI→HTTP→storage، ودورة العامل الداخلية باعتمادية الوقت المضبوط. لا اختبارات على dev أو تشغيل عامل فيها أثناء التنفيذ.

يوم العيادة بتوقيت Africa/Nouakchott (UTC+00:00): يغلق النشاط الأقدم من منتصف ليل اليوم. يقرر service الاستحقاق من arrivedAt للانتظار وstartedAt للزيارة الجارية؛ إذا ارتبط حضور قديم بزيارة بدأت اليوم، يبقى الاثنان جاريين حتى نهاية يوم الزيارة. لا تمس invalidEntries أو الأوقات الأصلية أو تدقيق04. لا زيارة عند إغلاق انتظار.

تحفظ attendance وvisit المغلقتان `autoClosure={effectiveClosedAt,recordedAt,reason:"clinic_day_end"}`؛ الأول منتصف الليل التالي ليوم النشاط، والثاني وقت المعالجة الفعلي. تبقى recordedEndAt خالية عند الإغلاق الآلي لأنه ليس إقرار موظف بالإنهاء. تحفظ بيانات الإغلاق بعد تصحيح النتيجة لاحقًا، مع حفظ تدقيق التصحيح الحالي. الأعمدة الجديدة اختيارية تراكمية، وقيود النهايات تسمح بهذه الدلالة دون إعادة كتابة الصفوف القديمة.

تملك repository اكتشاف العيادات من attendances فقط، والقراءة والتحديث المقيد بالإصدارات؛ ينسق service معاملة مستقلة بلا actor لكل عيادة بعد قفل العيادة القائم. تزيد إصدارات الحضور والزيارة مرة واحدة وتتحرر السعة معًا؛ الفشل يتراجع عن كليهما. التكرار لا يعيد كتابة التاريخ.

كل قراءة وكتابة visits تتدارك العيادة بمعاملة صيانة سابقة مستقلة، ثم تعيد قفل العيادة وتفويض actor والإصدارات للعملية البشرية. يسبق متحكم catchUp التحقق من UUID/body/query عند HTTP دون نقل Zod من controller؛ middleware المصادقة والمصدر وJSON تبقى كما هي. رفض مدخلات بشرية سليمة JSON أو تعارضها لا يتراجع عن الإغلاق السابق. JSON غير قابل للتحليل أو جلسة غير مخولة يرفضها HTTP المعتاد قبل دخول الميزة.

تعلن visits واجهة صيانة محدودة `maintain()` فقط للتركيب؛ لا HTTP جديد أو actor وهمي أو تغيير TransactionManager أو منح. يبدأ تركيب الخادم العامل عند listen الفعلي، ثم كل60 ثانية، دون تداخل، ويسجل الفشل ويعيد المحاولة. إيقاف الخادم يمسح المؤقت وينتظر التنفيذ الجاري قبل فصل قاعدة البيانات؛ استيراد app لا يبدأ مؤقتًا. catchUp داخلي لمسار HTTP والخدمة وليس منفذًا عامًا جديدًا للمستخدم.

يعرض تاريخ المريض الحالة الآلية وسببها والوقت المستحق ووقت المعالجة باللغتين دون تسمية ذلك اكتمالًا أو مغادرة مؤكدة، باستخدام Query والمكونات القائمة. تبقى البطاقة والتبويبات وحراس04/03 كما هي؛ لا CSS أو SSE أو store جديد. الاختبارات الجزئية والمتأثرة فقط أثناء05؛ المجموعة الشاملة للمكلف الرئيسي عند اكتمال الميزة وفق ADR0005. المتصفح والمراجعة ونسخة المستخدم وحفظها من مسؤولية الوكيل الرئيسي، ولا قبول بشري مفترض.
