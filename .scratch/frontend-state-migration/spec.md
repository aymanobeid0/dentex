# نطاق ترحيل إدارة حالة الواجهة

Status: ready-for-agent

هذه مساحة تذاكر التنفيذ المنشورة، وليست مواصفة بديلة. المصدر الوحيد للنطاق هو [المواصفة المعتمدة](../frontend-state/spec.md)، والقرار في [إدارة حالة الواجهة](../../docs/frontend-state.md). بند المتابعة الأب في مساحة frontend-state حُدّث بطلب المستخدم بعد نشر التذاكر ليعكس اعتمادها، ولم يُغلق.

اعتمد المستخدم صراحة التذاكر التسع وحجمها وحوافها بتاريخ2026-11-04، ثم طلب نشرها. فهرسها وحالة الحواجز في [map.md](map.md). لا تنفيذ خلال النشر ولا إعادة تهيئة لبيئة التطوير.
