# عقد07 — 2026-11-05 قبل التنفيذ

تبدأ07 بعد حفظ06 فيda5819f. نقاط TDD المعتمدة: الشاشات القائمة وHTTP والتزامن والعزل حيث ينطبق. لا تغيير خادم أو مخطط أو عقد إنشاء العيادة والمدير أو حساب مدير البرنامج؛ لا تحرير عيادة ولا بداية ترقيم ملفات.

تملكQuery قائمة العيادات وقراءات مديري العيادة بمفاتيح الجلسة ومعرف العيادة، وpolling للمعروض فقط. تبقى مسودة إنشاء العيادة عند زيارة الحساب وفق معمارية الواجهة القائمة، مع توقف polling هناك وإعادة التحقق عند العودة؛ التنقل الذي يفقد المسودة والإلغاء والخروج يحتاجان اختيار تجاهل صريح. تبقى مسودةreset أيضًا في الذاكرة عند إخفاء الشاشة، دون polling خلفي. الخروج وانتهاء الجلسة يمسحان النطاق والطلبات.

الإنشاء وreset عبرmutations بلاretry/queue، تمنع الكتابةoffline أو الإرسال الجاري. النجاح يحتاجDTO العيادة الصالح أو204 للـreset، ثم تحديث الموارد. حقول الأسرار مؤقتة فقط، والـmutation تضبطgcTime0 وتُصفّر بعد الاستقرار؛ لا أسرار فيkeys أو سجل أو تخزين دائم.

نتيجة408/500 أو فقد الرد أو نجاح تالف تبقى غير مؤكدة؛ لا إعادة تلقائية ولا تأكيد نجاح منpolling. تلزم قراءة يدوية جديدة تعرض القائمة/المديرين ثم إقرار صريح قبل محاولة يدوية أخرى. القائمة لا تضمن منع التكرار ولا تثبت نتيجة الطلب قطعًا؛ قراءة المدير لا تثبت كلمة المرور المخزنة. رفض القراءة يبطل المراجعة السابقة والجارية مع تجاهل ردها المتأخر. تحفظRadix والترجمات والاتجاه والتركيز والتصميم.
