# 09: إتمام الانتقال والتحقق عبر الشاشات

**What to build:** تطبيق متسق عبر جميع الشاشات الحالية، لا يعيد بيانات جلسة قديمة ولا يبقي جلبًا محليًا موازيًا للتدفقات المرحلة، مع تقرير تحقق كامل ومعيار واضح للميزات المقبلة.

**Blocked by:** 03 — تسجيل مريض وحماية مسودة التسجيل ووضوح نتيجة الحفظ؛ 05 — تعديل منح الدور مع حماية التعارض؛ 06 — إكمال دورة الموظف: الإنشاء والحالة وإعادة تعيين كلمة المرور؛ 07 — العيادات ومديروها عبر دورة البيانات الموحدة؛ 08 — الحساب الشخصي وتغيير كلمة المرور دون بيانات جلسة متبقية

**Status:** ready-for-agent

**Execution:** not-started

- [ ] حصر جميع قراءات وكتابات API وأصحابها وإزالة البقايا القديمة التي لا مستهلك لها؛ لا حذف واسع قبل انتقال مستهلكيه ولا تأجيل الاختبارات الأساسية إلى هذه التذكرة.
- [ ] فحص دورة تنقل كاملة بين المرضى والموظفين والأدوار والعيادات والحساب، مع انقطاع/عودة الاتصال وظهور/إخفاء التبويب وخروج/انتهاء جلسة ورد قديم؛ polling للمعروض فقط وعزل cache محققان.
- [ ] التحقق من حماية المسودات والكتابات المتعارضة ونتائج الحفظ غير المؤكدة عبر الشاشات، وعدم تخزين بيانات المجال أو الأسرار دائمًا مع بقاء اللغة.
