## بدء العمل

التذكرة01 جاهزة لفحص المستخدم بعد اكتمالها تقنيًا؛ لا يبدأ عمل آخر في هذا التكليف. بعد إنجازها واعتماد فحصها تصبح02 و04 و05 و07 و08 متاحة من حيث الاعتماديات. التنفيذ المفضل تتابعي حسب الأرقام مع فحص المستخدم بعد كل تذكرة؛ لا ينفذ توازٍ تلقائي.03 تنتظر02، و06 تنتظر04، و09 تنتظر03 و05 و06 و07 و08. تُحتسب الحواجز المنجزة فعليًا، ولا يعني ready-for-agent تجاوز الحجب.

كل شريحة تشمل اختبارات سلوكها والتحقق المحلي؛09 لا تؤجل إليها الاختبارات الأساسية. لا تغيير معماري أو اختبارات متخطاة أو إعادة تهيئة لعيادة arabesque/2000. لا يبدأ التنفيذ بمجرد نشر الملفات، ولا PR قبل فحص المستخدم.
