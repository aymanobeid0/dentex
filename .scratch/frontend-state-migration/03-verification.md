## النطاق المنفذ

- الحفظ عبر mutation تملكها ميزة المرضى، دون retry أو انتظار اتصال لإرسال كتابة مؤجلة. تتحدث موارد المرضى بعد تأكيد الخادم؛ لا نجاح تفاؤلي. تأكيد التسجيل يتطلب id ورقم ملف صالحين، ثم فتح الملف لمن يملك القراءة، أو إيصال رقم الملف لصاحب الكتابة وحدها.
- المسودة محلية مستقلة عن الاستعلامات والهوية المتجددة؛ لا localStorage/IndexedDB. تحذير beforeunload ضمن حدود المتصفح. التنقل داخل المرضى والقائمة الجانبية والخروج يطلب البقاء أو تجاهل المسودة عبر Radix Alert Dialog من client/ui؛ البقاء/Escape يحفظانها والتجاهل أو النجاح يزيلان dirty. التنقل أثناء الحفظ ينتظر انتهاء الطلب؛ الإغلاق لا يدعي إلغاء كتابة الخادم.
- الرد المفقود/جسم الرد الناقص/500 تعطي نتيجة غير مؤكدة وتحتفظ بالمسودة. إعادة الاتصال لا تعيد POST. قبل إعادة محاولة يدوية تُقرأ ملفات الهاتف المرسل من الخادم عبر جميع صفحات البحث، وتعرض الأسماء وأرقام الملفات وروابطها مع تحذير احتمال التكرار، خصوصًا للأطفال. لا مطابقة تلقائية أو ادعاء exactly-once. فشل المراجعة يبقي الإرسال محجوبًا؛ صاحب الكتابة وحدها يطلب مراجعة شخص مخول بالقراءة.
- لا تغيير API أو خادم أو ترحيل أو صلاحيات أو تصميم الشاشات القائمة. أضيفت حزمة Radix Alert Dialog المناسبة للتفاعل المعتمد، مع حفظ Select/Checkbox والاتجاه والتركيز.
