# عقد04 — أرشفة ملف المريض واستعادته — 2026-11-05

سُجل قبل كود04 بعد حفظ03 فيce26bb6. [المواصفة](spec.md) و[التذكرة](issues/04-archive-patient.md) مرجع النطاق؛ نقاط TDD المأذونة: الشاشة وHTTP والتزامن والصلاحيات وعزل العيادة. العمليات داخل طبقات موديول المرضى القائمة دون تغيير معماري أو صلاحية إضافية.

- ترحيل إضافي لعمود archived منطقي NOT NULL DEFAULT false؛ تبقى الملفات الموجودة نشطة دون تغيير حقولها أو أرقامها. تعيد التفاصيل وملخصات القائمة archived؛ القراءة بـpatients.read حتى للمؤرشف.
- GET /api/clinic/patients يقبل status اختياريًا: active الافتراضي، أو archived أو all. يُجمع الفلتر مع q/page وعزل العيادة؛ يبقى البحث المباشر300ms وEnter والمسح والصفحات كما هي. تغيير الفلتر يبدأ من الصفحة1 ويشمله query key؛ العودة من الملف تبدأ بحثًا فارغًا وحالةactive.
- PATCH /api/clinic/patients/:id/archive يقبل {archived:boolean,editVersion:positiveInteger<=2147483646} فقط، ويتطلب patients.write. نجاح200 يعيد id/fileNumber/editVersion الجديد/archived فقط. تبقى الهوية والحقول محفوظة، دون حذف أو تحرير للهاتف. كل عملية مقبولة تزيد الإصدار1 حتى مع الحالة نفسها؛ لا افتراض idempotency أو retry.
- يعاد تفويض الفاعل بعد قفل العيادة داخل المعاملة القائمة. الغائب أو خارج العيادة404، المدخلات400، الجلسة401، الصلاحية أو المصدر403، الإصدار القديم409 edit_conflict. يرفض PUT للمؤرشف409 patient_archived دون أثر جزئي؛ تبقى القراءة والاستعادة للمخول. قيد تفرد البالغ يشمل المؤرشف، والأرشفة والاستعادة لا تعدلان الهاتف.
- يستخدم التعديل والأرشفة والاستعادة القفل والإصدار نفسيهما: إن سبقت الأرشفة يُرفض التعديل، وإن سبقه التعديل تنجح كتابته قبل الأرشفة وتحتاج الأرشفة الإصدار الحديث. لا كتابة فوق ملف مؤرشف أو استئناف كتابة مؤجلة تلقائيًا.
- توضح الواجهة الحالة وسبب منع التحرير، وتعرض الأرشفة أو الاستعادة للمخول. يسبق الكتابة تأكيد Radix AlertDialog؛ الإرسال الجاري يمنع التنقل والتكرار. تستخدم Query mutation بلا retry أو صف offline أو نجاح متفائل. يحفظ التعارض أو الرد المفقود أو500/408 أو رد النجاح التالف سياق العملية ويتطلب تحديث الملف ومراجعته وإقرارًا صريحًا قبل إرسال يدوي جديد. إن أظهرت المراجعة تحقق الحالة المطلوبة، تُعرض الحالة دون إرسال آخر أو ادعاء تأكيد الطلب المفقود نفسه.
- العربية والفرنسية وRTL/LTR وRadix عبر client/ui، والمكتب والهاتف ولوحة المفاتيح وتدفق UI-to-API الحقيقي. اختبارات البيانات والترحيلات على dentex_test جديدة مؤقتة فقط؛ تحفظ dev وvolume والحسابات ونسخة المراجعة، ويُترك5151/5152 للمستخدم بعد check:dev كامل. لا ترقيم أو عقود مشتركة أو محتوى طبي.
