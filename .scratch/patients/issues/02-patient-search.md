# 02 — قائمة المرضى والبحث

Status: ready-for-human

**What to build:** يستطيع الموظف المخول العثور على المريض وفتح ملفه من قائمة مرضى عيادته.

**Blocked by:** 01 — تسجيل المريض وفتح ملفه الأساسي.

## Acceptance criteria

- [x] تعرض القائمة بيانات المرضى من الخادم وتتيح فتح الملف، وفق patients.read.
- [x] البحث بالاسم أو الهاتف أو رقم الملف؛ توحيد الهاتف يطابق التسجيل، ولا يُفترض أن الأسماء فريدة.
- [x] يعرض البحث بالهاتف جميع المشاركين المطابقين ضمن النطاق، مع تمييز الطفل ورقم ملف كل مريض.
- [x] لا تُسرّب نتائج أو تفاصيل من عيادة أخرى أو لمستخدم فقد صلاحية القراءة.
- [x] حالتا عدم وجود مرضى وعدم وجود نتائج بحث واضحتان؛ لا يتحول فشل الشبكة إلى قائمة فارغة مضللة.
- [x] المسار كامل عبر الواجهة وAPI والتخزين، مع اختبارات سلوك HTTP والصلاحيات وعزل العيادات ومنع وصول مدير البرنامج.
- [x] تعمل العربية والفرنسية واتجاهاتهما، مع حالات التحميل والفراغ والخطأ ومنع الإرسال المكرر؛ يُوثق التحقق البصري أو سبب تعذره.
- [x] يُحدد عقد العملية ويُوثق قبل التنفيذ وفق مواصفة المرحلة وقواعد تصميم المشروع؛ لا تُضاف وظائف مستقبلية.
