# 04 — أرشفة الملف واستعادته

Status: ready-for-human
Execution: complete

**What to build:** يستطيع من يملك تعديل المرضى أرشفة الملف واستعادته، مع الاحتفاظ بالبيانات وإتاحة القراءة والبحث حسب الحالة.

**Blocked by:** 02 — قائمة المرضى والبحث؛ 03 — تعديل بيانات المريض.

## Acceptance criteria

- [x] الأرشفة والاستعادة تتطلبان patients.write دون صلاحية جديدة، والقراءة تتطلب patients.read.
- [x] تخفي القائمة المؤرشف افتراضيًا وتتيح إظهاره بفلتر، ويطبق البحث الفلتر نفسه مع تمييز الحالة.
- [x] لا تحذف الأرشفة البيانات ولا تحرر رقم الملف أو الهاتف من قاعدة التكرار.
- [x] قراءة المؤرشف مسموحة للمخول؛ تُرفض تعديلات بياناته عبر الخادم حتى الاستعادة، وتوضح الواجهة السبب.
- [x] الاستعادة تعيد الملف بنفس الرقم والبيانات دون إنشاء نسخة جديدة.
- [x] تشمل اختبارات القاعدة بالغًا مؤرشفًا يمنع تسجيل بالغ آخر بالهاتف نفسه، والبحث بالهاتف المشترك مع فلتر الأرشفة.
- [x] لا يسمح سباق الأرشفة مع التعديل بتعديل ملف مؤرشف؛ لا يوجد حذف نهائي.
- [x] المسار كامل عبر الواجهة وAPI والتخزين، مع اختبارات سلوك HTTP والصلاحيات وعزل العيادات ومنع وصول مدير البرنامج.
- [x] تعمل العربية والفرنسية واتجاهاتهما، مع حالات التحميل والفراغ والخطأ ومنع الإرسال المكرر؛ يُوثق التحقق البصري أو سبب تعذره.
- [x] يُحدد عقد العملية ويُوثق قبل التنفيذ وفق مواصفة المرحلة وقواعد تصميم المشروع؛ لا تُضاف وظائف مستقبلية.
