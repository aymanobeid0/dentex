# 01 — تسجيل المريض وفتح ملفه الأساسي

Status: closed

**What to build:** يستطيع الموظف المخول تسجيل مريض وفتح بياناته الأساسية المحفوظة، برقم ملف ثابت وقواعد هاتف تراعي الأطفال.

**Blocked by:** None — can start immediately.

## Acceptance criteria

- [x] الاسم والهاتف والجنس إلزامية؛ تاريخ الميلاد والعنوان والملاحظة الإدارية اختيارية؛ خيار طفل صريح دون إلزام بيانات ولي الأمر.
- [x] تُقبل أرقام موريتانيا وتوحد صيغها وفق المواصفة؛ يُمنع بالغ ثانٍ بالرقم نفسه داخل العيادة، ويُسمح بعدة أطفال وبالغ واحد بغض النظر عن ترتيب التسجيل.
- [x] يولد الخادم رقم ملف فريدًا داخل العيادة لكل مريض، بما في ذلك الأطفال المشاركون في الهاتف.
- [x] يتيح الإنشاء بصلاحية patients.write، وفتح التفاصيل بصلاحية patients.read، دون منح القراءة ضمنيًا لمن يملك الكتابة فقط.
- [x] الملف يعرض البيانات الأساسية فقط؛ لا أقسام طبية أو مالية مستقبلية ولا بيانات تجريبية بوصفها حقيقية.
- [x] طلبان متزامنان لبالغين بالهاتف نفسه لا ينشئان سجلين؛ لا تتكرر أرقام الملفات تحت التزامن؛ فشل الإنشاء لا يترك سجلًا جزئيًا.
- [x] المسار كامل عبر الواجهة وAPI والتخزين، مع اختبارات سلوك HTTP والصلاحيات وعزل العيادات ومنع وصول مدير البرنامج.
- [x] تعمل العربية والفرنسية واتجاهاتهما، مع حالات التحميل والفراغ والخطأ ومنع الإرسال المكرر؛ يُوثق التحقق البصري أو سبب تعذره.
- [x] يُحدد عقد العملية ويُوثق قبل التنفيذ وفق مواصفة المرحلة وقواعد تصميم المشروع؛ لا تُضاف وظائف مستقبلية.
