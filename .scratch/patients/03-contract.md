# عقد03 — تعديل بيانات المريض — 2026-11-05

سُجل قبل كود التنفيذ وفق [المواصفة](spec.md) و[قرار الحالة](../../docs/frontend-state.md). نقاط TDD المأذونة: الشاشة، HTTP مع التخزين الحقيقي، طلبات متزامنة وصلاحيات وعزل العيادات. لا تغيير معماري؛ العمليات داخل موديول المرضى بطبقاته القائمة.

- GET التفاصيل يعيد editVersion موجبًا إضافة للحقول الحالية. ترحيل إضافي يهيئ الموجودين عند1 دون تعديل بياناتهم أو أرقامهم.
- PUT /api/clinic/patients/:id يستقبل الحقول السبعة المعتمدة نفسها كاستبدال كامل وeditVersion موجبًا حتى2147483646. لا يقبل id/clinicId/fileNumber أو حقولًا إضافية. الاختياري الفارغ يصبحnull؛ توحيد الهاتف نفسه كالتسجيل.
- patients.write مطلوبة دون منح القراءة ضمنيًا؛ العيادة من الجلسة ومدير البرنامج ممنوع. يعاد فحص الفاعل وصلاحياته بعد قفل العيادة داخل المعاملة القائمة.
- نجاح200 يعيد id/fileNumber/editVersion الجديد فقط؛ تبقى القراءة مستقلة. كل حفظ مقبول يزيد الإصدار مرة؛ الإصدار القديم409 edit_conflict، تعارض البالغ409 duplicate_phone، الغائب/خارج العيادة404، المدخلات400، الجلسة401، الصلاحية/المصدر403. الرفض ذري؛ قيد الهاتف الحالي يشمل جميع الملفات ويستثني السجل المعدل طبيعيًا.
- واجهة الملف تتيح التحرير للمخول الذي يستطيع قراءة الملف. المسودة محلية بلقطة الإصدار عند فتح التحرير، لا تستبدلها قراءات الخلفية. Query/mutation بلاretry أو نجاح تفاؤلي. الحفظ المؤكد يحدث الملف والقائمة؛ التعارض يحفظ المسودة ويتطلب مراجعة حديثة وإقرار متابعة الحفظ قبل استخدام الإصدار الجديد. الرد المفقود/500/408 أو نجاح تالف غير مؤكد؛ توضح الرسالة تعذر الاتصال والمحاولة لاحقًا واحتمال التنفيذ وتمنع الإعادة قبل مراجعة وإقرار. الإرسال الجاري أوoffline يمنع طلبًا جديدًا.
- حوار Radix لحماية المسودة مع التنقل والخروج وbeforeunload ضمن حدوده؛ العربية/الفرنسية وRTL/LTR ولوحة المفاتيح والمكتب والهاتف. لا أرشفة في03 أو ترقيم أو عقود مشتركة.
