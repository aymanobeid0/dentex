## العقد والنطاق

اعتمد المستخدم سلوك البحث والترتيب والصفحات في هذه الجلسة قبل التنفيذ. المصدر التفصيلي هو [عقد قائمة المرضى والبحث](../../docs/ui-contract.md#عقد-قائمة-المرضى-والبحث-المرضى-02). التنفيذ يضيف GET إلى موديول المرضى القائم؛ route للصلاحية، controller للتحقق، schema لتوحيد المدخلات، service للعملية، repository لاستعلام العيادة والإسقاط والترتيب والصفحات. لا تغييرات في المعمارية أو واجهات بين الموديولات أو مخطط البيانات أو فحوص المعمارية.

مدخل المرضى يعرض القائمة لصاحب القراءة، ويتيح التسجيل لصاحب الكتابة وفتح الملف لصاحب القراءة. رابط التسجيل `#patients/new` ورابط الملف القائم `#patients/<id>`. لا تعديل أو أرشفة أو أقسام طبية أو مالية أو أفعال جماعية.

المسار: دخول من الواجهة ← قائمة فارغة ← تسجيل بالغ وطفلين بهاتف مشترك من الواجهة ← القائمة ← البحث بالهاتف بصيغة عربية/00222 ← ظهور المشاركين الثلاثة وشارات الطفل ← فتح الملف. شمل أيضًا تبديل العربية والفرنسية واتجاه الصفحة، انتقال Tab من حقل البحث إلى الزر، عدم وجود نتائج، محاكاة 500 وإعادة المحاولة وإخفاء النتائج القديمة. عوينت لقطات المكتب والهاتف؛ لا تجاوز أفقي للصفحة أو overlay. الجدول على الهاتف قابل للتمرير الأفقي داخل بطاقته لإظهار الأعمدة الباقية.

المقاسات: 1440×1000، 390×844، 320×844، باللغتين. سجل الجولة الأخيرة بلا أخطاء console أو طلبات 404؛ ظهر طلب favicon قديم 404 في الجولة الأولى فقط. لا فحص لأجهزة فعلية أو متصفحات أخرى أو قارئ شاشة أو مقارنة بكسلات كاملة.
