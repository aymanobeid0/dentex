# 02-role-permissions: الأدوار والصلاحيات

Status: closed

Depends on: 01

## التنفيذ

نقل قراءة الأدوار وتعديل صلاحياتها وافتراضيات الإنشاء إلى الموديول المعلن. حفظ عدم تعديل admin وفحوص التفويض المتزامنة.

المرجع الملزم: docs/architecture.md وADR 0002 والخطة المعتمدة. هيكل كل موديول: routes/controller/service/repository/schemas/dto/errors/index. لا استثناءات معتمدة؛ لا وصول لجداول موديول آخر ولا أنواع Express أو Prisma داخل service.

## معيار الإتمام

اختبارات الصلاحيات الافتراضية وتعديل الأدوار وتحديث الجلسة وعزل العيادات.

حفظ عقود HTTP والسلوك الحالي والصلاحيات والمعاملات. تبقى التذكرة مفتوحة حتى التحقق من كامل نطاقها.

دليل التحقق الحالي في [التسليم](../handoff.md). إغلاق تذكرة التنفيذ لا يعني رفع التغييرات أو اعتمادًا بشريًا جديدًا للواجهة.
