# 07: إدارة مديري العيادة وحماية آخر مدير

**What to build:** تعيّن العيادة أكثر من مدير عند الحاجة، ويدير مدير البرنامج حسابات مديري العيادات، مع ضمان بقاء مدير نشط لكل عيادة.

**Blocked by:** 04: إدارة موظفي العيادة؛ 06: إدارة الحسابات وكلمات المرور.

**Status:** closed

- [x] يستطيع مدير العيادة إسناد دور المدير إلى موظف أو إزالته عندما يبقى مدير نشط آخر، وتُطبّق صلاحيات الإدارة فورًا.
- [x] تُرفض إزالة دور آخر مدير نشط أو تعطيله، حتى عند تنفيذ طلبات متزامنة؛ وتوضح الواجهة سبب الرفض.
- [ ] يستطيع مدير البرنامج عرض حسابات مديري عيادة وإعادة تعيين كلمة مرور مدير من لوحة إدارة العيادات، دون الاطلاع على بيانات المرضى الطبية.
- [x] تتبع إعادة تعيين كلمة المرور سياسة إبطال الرموز، ويُحافظ على عزل العيادات والتحقق من صلاحيات مدير البرنامج.
- [x] تُختبر الإدارة وحماية آخر مدير والتزامن وإبطال الرموز وعزل البيانات؛ تتوفر الواجهة بالعربية والفرنسية.
- [x] يبقى إجراء التحقق من هوية صاحب العيادة لاستعادة الوصول إجراءً تشغيليًا يحتاج تحديدًا؛ لا يُنشأ مسار استعادة عام بناءً على افتراضات.
- [ ] تتبع شاشة إدارة المديرين المرجع البصري وتدعم اتجاهي العربية والفرنسية.
