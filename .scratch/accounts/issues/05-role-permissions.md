# 05: تعديل صلاحيات الأدوار

**What to build:** يعدّل مدير العيادة صلاحيات الأدوار الجاهزة من لوحة التحكم، فيسري التغيير فورًا على الموظفين المعنيين داخل عيادته.

**Blocked by:** 04: إدارة موظفي العيادة.

**Status:** ready-for-human

- [x] تعرض الواجهة الأدوار الجاهزة وصلاحياتها، وتمكّن المدير من تعديل صلاحيات الطبيب والاستقبال مع توضيح أثر التغيير على حاملي الدور.
- [x] لا يتأثر دور مماثل في عيادة أخرى، ولا توجد صلاحيات فردية أو إمكانية إنشاء أدوار جديدة.
- [x] يحصل الموظف متعدد الأدوار على مجموع صلاحياتها، ويحتفظ المدير بجميع صلاحيات العيادة دائمًا.
- [x] تعتمد الطلبات المحمية على الصلاحيات الحالية في الخادم، فتسري الإضافة أو الإزالة في الطلب التالي حتى مع صلاحية JWT.
- [x] تشمل الصلاحيات المبدئية للطبيب عرض الحالة المالية للمريض عند تنفيذ الوحدة المالية، دون منحه تعديلها تلقائيًا؛ وتحدد صلاحيات الوحدات المستقبلية دون تنفيذ وظائفها.
- [x] تُختبر الصلاحيات والعزل والجمع والتغيير الفوري، وتدعم الواجهة العربية والفرنسية.
- [ ] تتبع شاشة الصلاحيات المرجع البصري وتدعم الاستخدام بلوحة المفاتيح.

## Comments

Implementation completed. نُفذت الصلاحيات وفُحص الحفظ وإعادة التحميل المكتبيان في اللغتين، واختُبر سباق تبديل الدور آليًا؛ يبقى فحص الهاتف ولوحة المفاتيح اليدوي الشامل. لا يعني هذا التصنيف إغلاق التذكرة قبل إتمام التحقق البشري.
