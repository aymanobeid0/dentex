# 03: دخول مدير العيادة وعزلها

**What to build:** يدخل مدير العيادة برمزها واسم المستخدم وكلمة المرور إلى مساحة عيادته، دون الوصول إلى عيادات أخرى.

**Blocked by:** 02: إنشاء عيادة ومديرها.

**Status:** closed

- [x] تعيد مساحة العيادة استخدام إطار التطبيق المشترك (Sidebar قابل للطي وNavbar)، مع قائمة تخص وظائف العيادة واتجاه صحيح لكل لغة والحفاظ على حالة الطي أثناء التنقل.
- [x] يتبع تنقل العيادة المحتوى المعتمد: الموظفون، والأدوار والصلاحيات، وحسابي؛ تظهر الأقسام عند اكتمال تذاكرها فقط، ولا تُعرض أقسام المرضى أو المالية غير المنفذة.
- [x] يدخل مدير العيادة باستخدام رمز العيادة واسم المستخدم وكلمة المرور إلى واجهة عربية وفرنسية، ويبقى دخوله صالحًا بعد تحديث الصفحة وفق إعدادات Cookie المتفق عليها.
- [x] تُرفض بيانات الدخول غير الصحيحة برسالة لا تكشف أي جزء منها صحيح، وتطبق حدود محاولات الدخول.
- [x] يحدد الخادم العيادة من الحساب المصادق عليه، ويفحص حالته الحالية وإصدار الاعتماد في الطلبات المحمية؛ لا يُعتمد على رمز العيادة وحده كصلاحية.
- [x] يُمنع الوصول إلى بيانات عيادة أخرى حتى عند تقديم معرّفاتها، ويُمنع الخلط بين حساب مدير البرنامج وحساب العيادة.
- [x] تُختبر حالتا النجاح والفشل وانتهاء الرمز والخروج وعزل عيادتين وفحص مصدر الطلبات.
- [ ] تتبع شاشة الدخول المرجع البصري مع الحقول المعتمدة، دون نسخ خيارات دخول أو استعادة خارج المواصفة.
