# 02: إنشاء عيادة ومديرها

**What to build:** ينشئ مدير البرنامج عيادة من لوحته باسم ورمز ومدير أول، وتظهر العيادة في القائمة جاهزة لدخول مديرها لاحقًا.

**Blocked by:** 01: دخول مدير البرنامج ولوحته.

**Status:** closed

- [x] يدخل مدير البرنامج اسم العيادة ورمزها المكون من أربعة أرقام واسم مديرها واسم المستخدم وكلمة المرور؛ تظهر رسائل التحقق بالعربية والفرنسية.
- [x] يحافظ الرمز على الأصفار الأولى ويكون فريدًا، ويُرفض الرمز المكرر أو غير المكوّن من أربعة أرقام.
- [x] تُنشأ العيادة والمدير والأدوار الجاهزة في معاملة واحدة، ولا تُحفظ بيانات جزئية عند الفشل.
- [x] لا يستطيع حساب غير مدير البرنامج إنشاء عيادة أو عرض قائمة العيادات الإدارية.
- [x] تغطي الاختبارات الإنشاء والصلاحية والتكرار وفشل المعاملة ومنع الوصول غير المصرح.
- [ ] تتبع شاشة إنشاء العيادة المرجع البصري ورموزه، وتعمل في اللغتين وعلى الأحجام المناسبة.
