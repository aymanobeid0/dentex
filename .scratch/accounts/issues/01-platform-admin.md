# 01: دخول مدير البرنامج ولوحته

**What to build:** يجهز صاحب البرنامج حساب مدير البرنامج بسكربت، ويسجل المدير دخوله ليرى لوحة تعرض قائمة العيادات. يعمل المسار على أساس تطبيق قابل للتطوير والتجربة بالعربية والفرنسية.

**Blocked by:** لا شيء؛ يمكن البدء فورًا.

**Status:** closed

الحالة الحالية: أُغلقت باعتماد المستخدم في 2026-11-02. مربعات التحقق وتعليقات التنفيذ أدناه تحفظ دليل الدفعة الأصلية، ولا تلغي هذا الاعتماد أو تمثل مهام مفتوحة الآن.

- [ ] تستخدم لوحة مدير البرنامج إطارًا مشتركًا من شريط جانبي قابل للطي وNavbar، مع تبديل اللغة والوصول للحساب والخروج، ودعم لوحة المفاتيح والهاتف. شاشة الدخول مستقلة.
- [x] تقتصر لوحة مدير البرنامج على قائمة العيادات بأسمائها ورموزها؛ تُضاف إجراءات الإنشاء وإدارة المديرين عند تنفيذ تذاكرها، دون أقسام غير منفذة أو إحصاءات خارج النطاق.
- [ ] تستخدم الواجهة Lucide React للأيقونات، باستيراد الأيقونات المستخدمة فقط، وتلتزم بأحجام وألوان المرجع البصري ودعم الاتجاه وإمكانية الوصول.
- [x] يعمل التطبيق بواجهة React وخادم Express 5 وTypeScript وقاعدة PostgreSQL وPrisma ضمن مشروع واحد، مع فصل بيئتي التطوير والإنتاج وبيانات تطوير وهمية.
- [x] ينشئ سكربت التشغيل حساب مدير البرنامج أو يحدثه دون إتاحة تسجيل عام، ولا يخزن أو يسجل كلمات المرور كنص صريح.
- [x] يدخل المدير ببياناته ويرى لوحة العيادات، مع عرض حالة مناسبة للقائمة الفارغة وتسجيل الخروج من جهازه.
- [x] يستخدم الدخول JWT صالحًا لمدة 24 ساعة في Cookie محمية، مع فحص مصدر الطلبات المغيرة للبيانات وحدود لمحاولات الدخول، وفق المواصفة.
- [ ] تُختبر حالات الدخول والخروج وفشل المصادقة وخصائص الحماية بالعربية والفرنسية.
- [ ] تتبع الشاشات المرجع البصري للمشروع ورموزه، وتدعم RTL وLTR دون إضافة وظائف غير مقررة من الصور.
