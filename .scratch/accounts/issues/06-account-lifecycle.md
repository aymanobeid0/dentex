# 06: إدارة الحسابات وكلمات المرور

**What to build:** يعطّل مدير العيادة حساب موظف ويعيد تفعيله أو يعيد تعيين كلمة مروره، ويستطيع الموظف تغيير كلمة مروره بنفسه.

**Blocked by:** 04: إدارة موظفي العيادة.

**Status:** ready-for-agent

- [ ] يستطيع المدير تعطيل موظف وإعادة تفعيله وإعادة تعيين كلمة مروره من واجهة عربية وفرنسية، دون حذف الحساب.
- [ ] يستطيع الموظف تغيير كلمة مروره بعد إدخال الحالية، وتُرفض كلمة المرور الحالية غير الصحيحة.
- [ ] يُمنع الحساب المعطل من الدخول فورًا، وتُبطل رموزه الحالية عند التعطيل أو تغيير كلمة المرور أو إعادة تعيينها، ولا تعود صالحة بإعادة التفعيل.
- [ ] لا يمكن تعطيل آخر مدير نشط، بما في ذلك عند تنفيذ عمليات متزامنة.
- [ ] تُختبر التدفقات والإبطال الفوري وحماية آخر مدير وعدم كشف كلمات المرور أو الرموز في السجلات.
- [ ] تتبع النماذج والنوافذ المرجع البصري، مع حالات واضحة للأخطاء والنجاح في اللغتين.
