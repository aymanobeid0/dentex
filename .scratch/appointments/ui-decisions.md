# قرارات واجهة المواعيد الحالية

2026-11-13. يجمع هذا السجل تعديلات الواجهة بعد ملاحظات المستخدم. يتقدم وصف الحالة الحالية هنا على لقطات وأحكام المطابقة التاريخية؛ لا يمثل طلب فتح PR اعتمادًا بصريًا شاملًا من المستخدم.

| ملاحظة المستخدم | التنفيذ الحالي | دليل التحقق |
| --- | --- | --- |
| الصفحة مزدحمة ومختلفة عن المرجع | شريط واحد وتقويم بعرض المحتوى؛ أزيل العمود الجانبي والتقويم المصغر والقائمة الدائمة. الفلاتر خلف زر مع عدد الفلاتر وإعادة الضبط؛ قائمة اليوم في نافذة عند الطلب. | [تبسيط الصفحة](ui-simplification-verification.md) |
| لا تظهر أسماء المرضى مباشرة | لا طلب مرضى ولا أسماء عند فتح الحجز أو فراغ البحث. منسدلة بالمطابقات بعد بحث مؤجل250ms، مع إخفاء النتائج القديمة فور تغير النص. اختيار بالماوس أو الأسهم وEnter، وإغلاق بـEscape وإرجاع التركيز. | [بحث المريض](patient-search-verification.md) |
| اقترح التسجيل إن لم يوجد المريض | يظهر الاقتراح بعد نجاح بحث بلا نتائج وبصلاحية تسجيل المرضى فقط؛ لا يظهر أثناء التحميل أو الخطأ. يستخدم نموذج التسجيل القائم عبر تركيب app، ويحفظ مسودة الحجز ويختار المريض بعد نجاح التسجيل المؤكد. | [التسجيل](03-verification.md)، [البحث](patient-search-verification.md) |
| حقول التاريخ والوقت تحتاج تصميمًا مخصصًا | DateField وTimeField مشتركان عبر Radix Dialog/Select، في الحجز وإعادة الجدولة وفلتر التاريخ. تاريخ ميلادي وتنقل لوحة مفاتيح؛ وقت24ساعة بكل الدقائق دون تقريب، مع تأكيد وإلغاء. هذا يحل محل قرار حقل الوقت الأصلي السابق. | [التاريخ والوقت](date-time-picker-verification.md) |
| الأطباء dropdown | SelectField مشتركة من Radix لاختيار طبيب واحد، بدل بطاقات الاختيار. تحفظ القيمة والمسودة والتعطيل عند الخطأ والانقطاع وفقد الصلاحية. | [قائمة الطبيب](doctor-dropdown-verification.md) |

## قواعد العرض الحالية وحدودها

- اليوم أعمدة أطباء على مقياس زمني؛ الأسبوع من الاثنين إلى الأحد بمقياس80px/ساعة ومواضع ثابتة وممرات للتداخل. الازدحام يقود إلى قائمة اليوم الكاملة بدل فقد المواعيد.
- الشهر كامل الأسابيع، بملخصين مختصرين و‎+N في رأس اليوم يفتح القائمة المشتركة. الهاتف يسمح بتمرير الشبكة داخل حاويتها. التفاصيل والتعديل في النافذة نفسها.
- البطاقات القصيرة تختصر البيانات لتقليل الازدحام؛ بيانات البداية والنهاية ورقم الملف والطبيب والحالة متاحة في التلميح/التفاصيل والقائمة. عرض الفرق عن الصياغة الأصلية45 و51 على المستخدم، واعتمد صراحة الإبقاء على هذا العرض وتوثيق تعديل البنود. حُدثت [المواصفة](spec.md)؛ [التدقيق](pr-spec-audit.md) يسجل نطاق الموافقة.
- الألوان والحدود والأبعاد والطبقات والحركة وملكية المظهر في [المكونات المشتركة](../../docs/ui-components.md)، والتفاعل في [Primitives](../../docs/ui-primitives.md)، والعقود في [عقد الواجهة](../../docs/ui-contract.md). CSS الميزة للتكوين؛ لا تجاوز لمالك مشترك.
- الخطوط محلية ومرخصة بـOFL، والواجهة عربية/فرنسية مع اتجاه وتركيز ورسائل حالات. لا ادعاء مطابقة بكسلية أو فحص قارئ شاشة فعلي أو هاتف مادي.
- تعديلات المرضى السابقة محفوظة: قائمة بأربعة أعمدة، وحالة في تلميح، دون عمود طفل أو أزرار تسجيل إضافية في الملف. بيانات الطفل تبقى في التسجيل والملف.
- لا إضافة لزيارة علاجية أو مالية أو WhatsApp أو توفر وهمي من الصور. لا تغيير للصلاحيات أو عقود API أو إعادة إرسال تلقائي أو نجاح تفاؤلي بسبب هذه التعديلات.
