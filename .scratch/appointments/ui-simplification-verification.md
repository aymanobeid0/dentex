# تبسيط صفحة المواعيد بعد رفض التصحيح الأول

2026-11-13. قال المستخدم إن الصفحة ما زالت مزدحمة ومشوهة بصريًا وإنه غير راض تمامًا. لذلك لا يُعد التصحيح السابق أو نجاح الاختبارات اعتمادًا للمظهر. هذا هو دليل النسخة الأحدث، التي تنتظر مراجعة المستخدم.

## التغيير المرئي

- أزيل العمود الجانبي الدائم بالكامل، بما فيه التقويم المصغر وقائمة اليوم المكررة. أصبح التقويم بعرض المحتوى.
- بقي شريط واحد للتاريخ والتنقل واليوم/الأسبوع/الشهر والتصفية والحجز. التاريخ المباشر والبحث والطبيب والحالة تظهر داخل Disclosure من Radix عند الضغط على «تصفية»، مع مسح الفلاتر ومؤشر عددها. التطبيق يحتفظ بنفس الاستعلامات والعقود.
- النقر على تاريخ داخل الشهر أو +N يفتح قائمة اليوم في Modal مشتركة؛ ومنها تُفتح التفاصيل وإجراءاتها. القائمة لا تزاحم الشبكة وهي مغلقة، وتحتوي كل نتائج اليوم الموجودة في الفترة. صفحات اليوم50 باقية، ويظهر تنقل الصفحات عند وجود أكثر من صفحة فقط.
- يحافظ اليوم والأسبوع على مقياس80px للساعة. أعمدة اليوم تشمل الأطباء الفعليين من المراجع والنتائج، دون اختراع توافر أو إجازات. البطاقات القصيرة تعرض ما يتسع من الاسم والوقت، وتبقى المعلومات الكاملة في التلميح والتفاصيل بدل قص السطر الثالث.
- نُقل +N إلى صف رقم اليوم، وظل الشهر يعرض شريطين دون تضخيم الصف المزدحم. تظهر أسابيع الشهر كاملة، مع تمرير أفقي داخل الحاوية على الهاتف.
- أزيل صنف patient-back من زر الحجز: كان يستعير هامشًا من CSS ميزة المرضى ويزيح الزر عن الشريط. زر الحجز يستخدم المظهر المشترك مباشرة. أزيلت الأنماط غير المستخدمة للتقويم المصغر، ووُحد ترتيب أدوات الهاتف.
- يقدَّم خط IBM Plex Sans Arabic في --font-sans عند lang=ar، والخط الفرنسي في الفرنسية. أثبت المتصفح تحميل خط اللغة المستخدمة؛ لا يُشترط أن يحمل المتصفح الخط الآخر غير المستخدم في السياق نفسه.

## التحقق وحدوده

نجحت205/205 اختبارات client بعد التبسيط، والبناء والأنواع وcheck:ui-styles وcheck:frontend-architecture. حد تحذير الحزمة لم يتغير، والتحذير الحالي نحو666KB باقٍ. بعد تنظيف CSS غير المستخدم أُعيد فحص الملكية، وشغّل Chromium النسخة ذات البيانات الأكثر كثافة؛ لا توسيع غير لازم لاختبارات الخادم في تغيير UI فقط.

الأدلة المحلية المستثناة من Git في `.worktrees/appointments-simplify/`: `client.json`، `visual.json`، `busy-visual.json`، واللقطات ar/fr لليوم والأسبوع والشهر والحجز على1592×960 و1440×1000 و900×1100 و390×844. كانت API مصطنعة للقراءة فقط مع منع جميع طلبات الكتابة. فُحصت نسخة قليلة البيانات وأخرى فيها27 موعدًا في اليوم وعدة أطباء. أثبتت الآلة غياب العمود الجانبي وحقول البحث من الحالة الافتراضية، وفتح قائمة اليوم والوصول إلى الموعد الثالث، وعدم overflow للصفحة، ومقياس الساعات، وTab وEscape وحراسة مسودة الحجز، وحدود النافذة وأحجام36/40/44. لا يثبت ذلك رضا المستخدم أو التطابق البكسلي.

قورنت اللقطات الحالية مع Calendar وDayView وBooking المرجعية؛ المقصود إزالة التكرار وإعطاء الشبكة الأولوية. الإطار المشترك وحقل الوقت الأصلي وأبعاد اللمس المعتمدة باقية. لا حقول علاجية أو مالية أو توافر مصطنعة. لا تغيير معماري أو خادم أو صلاحيات أو واجهات ميزات معلنة، ولا حزم جديدة.
