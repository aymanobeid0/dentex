# 05: التقويم الأسبوعي والشهري

**What to build:** يبدل الموظف بين اليوم والأسبوع والشهر؛ يرى الأسبوع شبكة أيام وساعات والشهر شبكة أيام بملخصات المواعيد، وينتقل بين الفترات ويفتح التفاصيل بالبيانات والصلاحيات نفسها.

## Acceptance criteria

- [ ] الأسبوع الاثنين إلى الأحد، والشهر ميلادي كامل، والوقت بتوقيت العيادة وأربع وعشرين ساعة مهما اختلف توقيت جهاز الموظف.
- [ ] قراءة الفترتين دون إسقاط مواعيد بسبب حدود الأيام أو صفحات العرض، ووضوح المواعيد المتزامنة لأطباء مختلفين. عند ازدحام يوم يبقى الوصول إلى كل موعد ممكنًا دون حد أعمال جديد للعدد.
- [ ] الفلاتر والبحث داخل الفترة المختارة، وكل الحالات افتراضيًا مع تمييز الملغى والتنبيه للمريض المؤرشف والطبيب غير المؤهل.
- [ ] فتح تفاصيل02، واستخدام إجراءات الحجز والتعديل والحالات المتاحة عندما تنفذ تذاكرها دون تكرار قواعدها أو إظهار إجراءات مستقبلية. لا سحب وإفلات أو دوام إلزامي.
- [ ] عند تنفيذ04 قبلها تستخدم التقويمات الإجراءات المكتملة؛ وعند تنفيذها قبل04 تظل قابلة للفحص بالعرض والتفاصيل المنشورة. إضافة إجراءات04 لاحقًا تتكامل مع التفاصيل المشتركة دون تذكرة سادسة خفية.
- [ ] اختبارات حدود الأسابيع والأشهر والسنوات ومنتصف الليل واختلاف توقيت الجهاز والازدحام والردود القديمة وعزل الصلاحيات.
- [ ] فحص حقيقي للشبكتين باللغتين والهاتف والمكتب ولوحة المفاتيح والتركيز، دون الاعتماد على اللون وحده، وقراءة مواعيد محفوظة فعلًا.

- [ ] تُوثق عقود العمليات قبل الكود، ويُلتزم بالمعمارية وملكية الوحدات والمعاملات والواجهات المعلنة. أي توسعة معمارية محكومة بالإذن تُعرض محددة للمستخدم وتنتظر موافقته قبل تطبيقها؛ اعتماد التقسيم ليس هذا الإذن.
- [ ] تُطبق مراجع تصميم الواجهة والمكونات العامة وإدارة الحالة والمهارات الهندسية المعتمدة دون تخفيف للفحص أو استيراد داخليات ميزات أخرى.
- [ ] تنجح اختبارات سلوك هذه الشريحة من الواجهة إلى التخزين مع الاختبارات التكاملية المناسبة على قاعدة مصطنعة معزولة، وفحص فعلي للعربية والفرنسية والهاتف والمكتب ولوحة المفاتيح؛ يسجل أي تحقق متعذر بوضوح ولا يدعى نجاحه.
- [ ] تنجح فحوص النوع والبناء ومعماريتي الخادم والواجهة والمراجعة المطلوبة مقابل main مجلوب حديثًا مع تثبيت الالتزام وشمول الملفات الجديدة والعمل غير الملتزم به.
- [ ] تُحفظ قاعدة التطوير وحساباتها وبيانات المستخدم دون تهيئة أو تغيير أسرار أو منح أو اختبارات عليها. بعد التنفيذ تُثبت نسخة التطبيق ومصدرها وقاعدتها وتُترك تعمل لفحص المستخدم قبل طلب دمج، وتُحدّث أدلة التحقق والتسليم والفهرس دون أسرار.
