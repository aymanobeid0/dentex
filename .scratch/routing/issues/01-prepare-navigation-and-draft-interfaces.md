# 01: تهيئة عقود العرض والتنقل وحراسة المسودات

**What to build:** إعادة تنظيم تمهيدية تحفظ السلوك القائم وتضع قراءة العنوان وترجمة التنقل في طبقة تركيب التطبيق. تعمل روابط المرضى الحالية والتسجيل ونوعا الدخول وحوار مغادرة كل نموذج كما قبل، وتصبح الميزات جاهزة لتلقي وصف العرض وطلب التنقل دون إدارة سجل المتصفح.

**Blocked by:** None (can start immediately). لا حواجز تذاكر؛ التنفيذ يحتاج تكليفًا لاحقًا.

Status: ready-for-human
Execution: complete

**تهيئة قبل الانتقال:** هذه تهيئة واحدة للعقود المعتمدة، وهي الاستثناء التمهيدي المسموح قبل الشرائح الوظيفية في مهارة التقسيم. تضيق تذكرة تشغيل الموجّه وتمنع جمع تفكيك الحراسة وتغيير الروابط والتحقق من الإنتاج في سياق واحد. لا مصدر تنقل جديد أو مكتبة توجيه موازية في هذه الخطوة؛ طبقة التطبيق وحدها تترجم العناوين القديمة حتى تستبدلها02.

## Acceptance criteria

- [ ] مدخل عرض المرضى ومخرج التنقل ونوع الدخول ومدخله ومخرج تبديله تطبق حسب العقود المعتمدة، دون كشف داخليات أو استيراد الموجّه داخل الميزات.
- [ ] تنتقل قراءة وكتابة العنوان القديمة من المرضى إلى تركيب التطبيق، مع بقاء العناوين الحالية وسلوك التسجيل والملف والعودة للقائمة وصلاحيات الكاتب والقارئ كما هي؛ لا اعتماد عنوان نظيف جزئي أو ازدواج إدارة للسجل.
- [ ] يتلقى الحارس رد البقاء الاختياري؛ النظافة تتابع، والتجاهل يمسح ثم يتابع مرة، والبقاء وEscape والانشغال يلغون المحاولة. تراجع تسجيلاته لكل التدفقات الحالية وتبقى استدعاءاته البسيطة صالحة.
- [ ] يبقى حفظ مسودة العيادات عند الحساب وحماية الخروج والأسرار وعزل الجلسة والتحديث الدوري للمعروض فقط، دون نقل بيانات الميزات إلى حالة عامة.
- [ ] يثبت عدم تغير السلوك باختبارات التدفقات القائمة وتحقق فعلي للمرضى والدخول وحراسة النماذج واستبقاء العيادات باللغتين. لا اختبارات لتفاصيل تنفيذ callbacks أو ملف بعينه.

- [ ] تُطبق فقط خريطة التوجيه والعقود المعمارية المحددة المعتمدة؛ لا تغيير لملكية الهوية وبيانات الخادم أو حدود الوحدات أو تخفيف للفحوص، وأي تغيير آخر يعرض للموافقة قبل تطبيقه.
- [ ] يثبت سلوك الشريحة من الواجهة والطلبات الفعلية المناسبة، لا تفاصيل تنفيذها؛ تنجح اختبارات نطاقها واللغتين والاتجاهين والهاتف والمكتب ولوحة المفاتيح، ويسجل أي تحقق متعذر بوضوح دون ادعاء نجاح.
- [ ] تنجح فحوص النوع والبناء ومعماريتي الخادم والواجهة والمراجعة المطلوبة مقابل main مجلوب حديثًا مع تثبيت الالتزام وشمول الملفات الجديدة والعمل غير الملتزم به.
- [ ] تُحفظ قاعدة التطوير وحساباتها وأسرارها ومنحها وبيانات فحص المستخدم دون تهيئة أو اختبارات عليها؛ البيانات المصطنعة في بيئة معزولة فقط، ولا مخطط أو ترحيل مطلوب لهذا الانتقال.
- [ ] بعد التنفيذ تُثبت نسخة التطبيق ومصدرها وقاعدتها ويترك التطبيق وقاعدة التطوير يعملان لفحص المستخدم وفق الإجراء المعتمد، مع تحديث دليل التحقق والفهرس والتسليم؛ لا طلب دمج قبل انتهاء فحصه.
