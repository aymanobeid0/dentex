# 02: تشغيل التوجيه الموحد والرئيسية والروابط المحمية

**What to build:** تصبح للشاشات الحالية كلها العناوين المعتمدة وتعمل الروابط والرجوع والتقدم تحت موجّه واحد، مع رئيسية العيادة الخفيفة ونوعي الدخول وصلاحيات الصفحات والروابط القديمة وقواعد العودة بعد الدخول وانتهاء الجلسة.

**Blocked by:** 01: تهيئة عقود العرض والتنقل وحراسة المسودات

Status: ready-for-human
Execution: complete

## Acceptance criteria

- [x] تنفذ الخريطة المعتمدة كلها، والعنوان مصدر الشاشة الوحيد؛ تزال حالة التنقل القديمة كمرجع مستقل. تبقى الإجراءات الداخلية بلا مسارات إضافية والبحث والمسودات خارج العنوان.
- [x] رئيسية العيادة معلومات الحساب والعيادة الفعلية فقط وتبقى حسابي مستقلة، وافتراضية مدير البرنامج العيادات. لا إحصاءات أو مواعيد أو أرقام تمثيلية.
- [x] يتحكم عنوان الدخول في نوع النموذج، مع حفظ الحقول غير السرية ومسح كلمة المرور والخطأ عند التبديل. الجلسة الصالحة على صفحة دخول تفتح افتراضيتها دون تبديل حساب تلقائي.
- [x] فتح محمي أول مرة دون جلسة يعود إلى الوجهة الداخلية المسموحة بعد الدخول؛ انتهاء جلسة معلومة أثناء الاستخدام أو الخروج يلغي المقصد ويفتح الافتراضية بعد الدخول. التشغيل الجديد بلا معرفة سابقة يتبع قاعدة الفتح الأول دون تتبع دائم.
- [x] تظهر الهوية قيد التحقق وفشل شبكتها بوضوح؛ لا عرض محمي قبل التحقق أو بيانات لجلسة سابقة أو تجاوز للصلاحية. صاحب كتابة المرضى دون القراءة يفتح التسجيل، والصفحة المعروفة غير المسموحة تعرض المنع، والمجهولة عدم الوجود.
- [x] تحول روابط المرضى القديمة باستبدال السجل دون حلقة رجوع، ولا تفتح مقصدًا خارجيًا أو تتجاوز نوع الحساب أو عزل العيادة.
- [x] تربط الحراسة بمحاولة الموجّه نفسها؛ البقاء يلغيها ويحفظ العنوان والسجل، والتجاهل يتابع مرة، والإرسال لا ينشئ انتظارًا مؤجلًا. تبقى مسودة العيادات وسياقها عند زيارة الحساب والعودة، ويتوقف استعلامها غير المعروض ويبقى طي الشريط.
- [x] تختبر هذه التذكرة كل سلوك التوجيه من المتصفح مع تدفقات الخادم المصطنعة المناسبة، والصلاحيات والهوية والسجل والمسودات واللغتين والهاتف والمكتب ولوحة المفاتيح. لا تؤجل اختبارات العميل أو العزل أو المنع إلى03.
- [x] تستخدم المكتبة بنمط المتصفح المعتمد مع بقاء Query مالك البيانات. تثبت نسخة الحزمة والقفل ومتطلبات التشغيل وفق القرار، دون تغيير عقود بيانات الأعمال أو المعمارية خارج الإذن.

- [x] تُطبق فقط خريطة التوجيه والعقود المعمارية المحددة المعتمدة؛ لا تغيير لملكية الهوية وبيانات الخادم أو حدود الوحدات أو تخفيف للفحوص، وأي تغيير آخر يعرض للموافقة قبل تطبيقه.
- [x] يثبت سلوك الشريحة من الواجهة والطلبات الفعلية المناسبة، لا تفاصيل تنفيذها؛ تنجح اختبارات نطاقها واللغتين والاتجاهين والهاتف والمكتب ولوحة المفاتيح، ويسجل أي تحقق متعذر بوضوح دون ادعاء نجاح.
- [x] تنجح فحوص النوع والبناء ومعماريتي الخادم والواجهة والمراجعة المطلوبة مقابل main مجلوب حديثًا مع تثبيت الالتزام وشمول الملفات الجديدة والعمل غير الملتزم به.
- [x] تُحفظ قاعدة التطوير وحساباتها وأسرارها ومنحها وبيانات فحص المستخدم دون تهيئة أو اختبارات عليها؛ البيانات المصطنعة في بيئة معزولة فقط، ولا مخطط أو ترحيل مطلوب لهذا الانتقال.
- [x] بعد التنفيذ تُثبت نسخة التطبيق ومصدرها وقاعدتها ويترك التطبيق وقاعدة التطوير يعملان لفحص المستخدم وفق الإجراء المعتمد، مع تحديث دليل التحقق والفهرس والتسليم؛ لا طلب دمج قبل انتهاء فحصه.
