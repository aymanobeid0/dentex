# القرارات المشتركة لمكونات الواجهة

المرجع الموحد لملكية تنسيق المكونات وقواعدها. اعتمد المستخدم في2026-11-12 تنفيذ `dentex_ui_audit_v2.md` وتثبيت القرارات المشتركة في ملف واحد. يحل هذا القرار محل اختلاف أحجام الأزرار السابق واختيار الألوان والحركة الوارد في المراجع الأقدم ضمن نطاق التقرير. لا يغير طبقات React أو الخادم أو العقود أو الصلاحيات.

## الملكية

| المصدر | المسؤولية |
| --- | --- |
| `design-tokens.css` | القيم المشتركة للألوان والأبعاد والطبقات والمدد، والتكيف مع المقاسات |
| `client/shared/styles/base.css` | التهيئة العامة والخط والاتجاه، دون تعريف مكونات |
| `client/ui/components.css` | الأزرار والأيقونات والحقول والبطاقات والجداول والشارات وحالاتها المشتركة |
| `client/ui/primitives.css` | تركيب ومظهر Radix: القوائم والنوافذ والتلميحات والاختيار |
| `client/ui/motion.css` | تعريف الحركات وسياسة تقليل الحركة |
| `client/app/layout/layout.css` | توزيع الشريط والقائمة ومساحة الصفحة فقط |
| `client/features/*/*.css` | ترتيب محتوى الميزة ومقاساتها الخاصة؛ لا إعادة تعريف شكل أو ارتفاع مكوّن مشترك |
| `client/app/styles.css` | تركيب المصادر فقط، دون قواعد إصلاح متأخرة |

تستخدم المكونات والميزات متغيرات الرموز؛ لا تضيف قيمًا بديلة لارتفاع الزر أو الحقل في الصفحة. يخص نموذج الدخول تركيبَه الخاص، وتبقى حدوده المحايدة وautofill الأبيض. لا CSS عام أو selector علىbody داخل ميزة لإصلاح نافذة أو قائمة مشتركة. يُصلح الخلل عند مالك المكوّن.

## الأبعاد والحالات

الأزرار النصية وأزرار الأيقونات والاختيار وحقول الأشرطة:36px للمكتب،40px حتى1194px،44px حتى760px. الرمز `--control-h` هو المرجع التكيفي؛ `--icon-btn` يتبعه. عناصر التنقل والcheckbox والأيقونات الزخرفية ليست أزرار إجراء ولا تُمط تلقائيًا لهذه الأبعاد. أزرار الدخول الأساسية وحقوله تحتفظ بارتفاعها الخاص42px على المكتب، وتبلغ44px للهاتف/اللمس.

`.ui-button` زر ثانوي أبيض بحد محايد وظل زر خفيف؛ استُبدل الاسم القديم `.language` في الاستعمالات الحالية بالاسم العام، وتظل أزرار تغيير اللغة مستقلة بوظيفتها.

`.primary.action` للفعل الأساسي، و`.icon-btn` لإجراء أيقونة مربع متساوي الأبعاد مع اسم وصول وتلميحRadix. الأيقونات الثانوية محايدة في السكون، وتكشف اللون عندhover أوfocus-visible عبرhover-primary/warning/danger/success. الاستعادة والتفعيل يمكن إظهارهماsoft-success. لا تلوين دائم لكل إجراءات الصفحة. لا تضيف الميزات قواعد لهذه الحالات.

حلقة التركيز الهادئة في حقول التطبيق والقوائم كما في التقرير، مع حد محايد؛ نموذج الدخول يبقي المعالجة المحايدة المعتمدة. يجب إبقاء التركيز مرئيًا بلوحة المفاتيح، ولا يعتمد المعنى علىhover أواللون وحده. حالاتdisabled واضحة بلا حركة ضغط أوhoverفاعلة.

## الطبقات والحركة

رموز مشتركة لغطاء النافذة100 ومحتواها101 والقائمة110 والتلميح120. لا يعالج موديول المواعيد أو غيره تراكبRadix بقاعدة خاصة. المحتوى المحجوب خلفalertdialog غير قابل للنقر، مع بقاء ترتيب التركيز تحت إدارةRadix.

المدد120/180/240ms والمنحنىcubic-bezier(0.16,1,0.3,1). الضغطtranslateY(0.5px) scale(0.985)، دخول البطاقةsurface-enter، والنوافذdialog-enter، والقوائمpopper-enter، وتدرج بيانات المريض20–145ms. الغطاءblur2px. عندprefers-reduced-motion تتوقف حركات الدخول والضغط والتدرج المكاني، وتبقى انتقالات الألوان والشفافية؛ لا يُستخدمtransform:none علىكلالعناصر لأنه يُفسد تمركزالنوافذ ومواضعالقوائم.

## تركيب ملف المريض

بطاقة بعرض المحتوى: هوية دائرية56px من أول حرفين، عنوان20px/600 وحالةوشارةطفل، رقم الملف تحته، وإجراءات التعديل والأرشفة في طرف الترويسة المقابل. شبكة البيانات3أعمدة وصفين بخطوطsoft وحشو16×24، ثم عمودواحد للهاتف. أزرار الوظائف تحافظ على callbacks والصلاحيات وحراسة المسودة؛ لا تغييرات HTTP أو نقل بيانات بين الميزات لأجل التنسيق.

## شرط قبول أي تعديل لاحق

يفرض `npm run check:ui-styles` ملكية المحددات المشتركة، وتعريف رموز الأبعاد والمدد والطبقات فيdesign-tokens.css، وتعريفkeyframes فيui/motion.css، وبقاءapp/styles.css للتركيب فقط. يعمل فيCI ويُختبر بأمثلة مقبولة ومخالفة. لا يغني عن فحصcomputed styles والمتصفح أو يكشف كل محدد CSS محتمل؛ القاعدة المعمارية أشمل من الفحص الآلي المحدود.

يفحص التعديل تعريف المكوّن ومواضع استعماله، ويقارن المرجع واللقطة وقياساتgetBoundingClientRect والحالات في اللغتين وRTL/LTR والمكتب والتابلت والهاتف ولوحة المفاتيح وتقليل الحركة. نجاح اختبارات الوظائف وحده لا يثبت التطابق البصري. توثق الفروقات المتبقية وقيود الفحص، وتبقى بيانات التطوير محفوظة. أي خروج عن هذا القرار أو حدود الموديولات يحتاج موافقة المستخدم وفق المعمارية المعتمدة.

تعلن Modal مقاسين default/wide عبر خاصية size؛ تملك primitives.css العرضين، وتختار الميزة المقاس دون selector على داخلية النافذة. يملك IconButton تركيب التلميح والاسم المقروء واللون الدلالي، وتستعمله جداول الإجراءات والشريط المشترك.
