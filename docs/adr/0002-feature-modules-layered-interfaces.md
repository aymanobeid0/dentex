# موديول لكل ميزة مع طبقات داخلية وعقود معلنة

التاريخ: 2026-11-03
الحالة: معتمد؛ اكتمل ترحيل الحسابات والتحقق محليًا في 2026-11-03. حالة الرفع في `.scratch/architecture/handoff.md`.

## السياق

قبل هذا القرار كان التنفيذ يجمع معالجة HTTP وقواعد العمل واستعلامات Prisma في ملفات الميزات، ويجمع إعداد التطبيق مع عمليات متعددة. طلب المستخدم فصلًا صريحًا قبل توسيع النظام بالمرضى.

## القرار

نعتمد Module لكل ميزة، بطبقات route/controller/service/repository ومخططات Zod وDTOs وأخطاء خاصة، مع Interface معلنة للتواصل. service يملك نطاق المعاملة وTransactionManager يخفي Prisma. الأخطاء تمر عبر معالج مركزي. المرجع التفصيلي الوحيد هو ../architecture.md.

## البدائل والمقايضة

رُفض إبقاء جميع المسؤوليات في ملف الميزة رغم قلة ملفاته، لأنه يخالف الفصل المطلوب ويصعّب إعادة استخدام قواعد العمل. اختير Module لكل ميزة بدل Module لكل عملية لتجميع القواعد المشتركة. يزيد عدد الملفات وكلفة التجميع، مقابل وضوح المسؤوليات وإمكانية فرض قواعد الاعتماديات آليًا.
