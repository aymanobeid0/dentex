# توجيه متصفح تملكه طبقة تركيب التطبيق مع بقاء بيانات الخادم في Query

التاريخ: 2026-11-11. الحالة: قرار معماري محدد معتمد بإجابتي١٩ و٢٠ في [مقابلة التوجيه](../../.scratch/routing/design.md)؛ التنفيذ لم يبدأ. [الخريطة وعقود الربط](../../.scratch/routing/architecture-proposal.md) تحددان نطاق الموافقة، ولا تحلان محل تكليف تنفيذ لاحق.

اختار المستخدم React Router بنمط البيانات ومسارات نظيفة لكل الشاشات الحالية قبل المواعيد، بدل التنقل اليدوي العام وروابط المربع للمرضى. ملكية العنوان والتحويلات وحراسة المغادرة في طبقة تركيب التطبيق، والميزات تتلقى وصف العرض وتطلب التنقل عبر واجهات معلنة؛ تبقى الهوية في المصادقة وبيانات الخادم في Query. اختير نمط البيانات للاستفادة من حراسة التنقل، رغم عدم نقل جلب الأعمال وحفظها إلى نظام الموجّه، حفظًا لقرار ملكية البيانات ومنع تعدد مصادرها.

يقابل توحيد الروابط ودعم الرجوع والفتح المباشر كلفة انتقال لعقود المرضى والدخول والحارس وإعداد تقديم صفحة التطبيق من الخادم. تحفظ روابط المرضى القديمة بالتحويل، وتبقى مسودة العيادات عند زيارة الحساب. الإذن يقتصر على [تفاصيل معمارية الواجهة](../frontend-architecture.md) و[تجهيز الطلبات](../architecture.md)؛ لا استثناء لاعتماديات أو تغيير لخدمات الأعمال أو قاعدة البيانات. الروابط المستقلة العامة وتوافقها سبب لتسجيل المقايضة قبل الكود بدل تركها تفصيلًا محليًا يسهل تغييره بلا أثر.
