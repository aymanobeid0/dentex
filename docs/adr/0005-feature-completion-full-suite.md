# الاختبارات الشاملة عند اكتمال الميزة

الحالة: معتمد بقرار المستخدم في2026-11-14.

تُنفذ اختبارات التذكرة الجزئية والمتأثرة بعد تنفيذ كل تذكرة، وتُشغّل المجموعة الشاملة (`full suite`) بعد آخر تذكرة في الميزة واكتمال المواصفة كلها، وليس قبل ذلك. طلب المستخدم هذا الترتيب صراحة لتجنب تكرار المجموعة الشاملة قبل اكتمال العمل.

تبقى دورات TDD أثناء التطوير، والفحوص المستهدفة للأنواع والبناء والمعمارية والواجهة والترحيل بحسب التغيير. في بوابة اكتمال الميزة تُشغّل المجموعة الشاملة ومانع التقرير؛ إذا احتاجت إصلاحًا، يُتحقق من الإصلاح ثم تُستكمل بوابة الشمول دون تخطٍّ أو ادعاء نجاح غير مشاهد. نتائج التشغيل الشامل للتذاكر01/02 قبل هذا القرار أدلة تاريخية، وليست تعليمات بتكرارها للتذاكر التالية.
