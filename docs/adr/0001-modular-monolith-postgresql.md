# تطبيق موحّد منظّم إلى وحدات مع PostgreSQL

نبدأ بتطبيق يخدم عدة عيادات مستقلة، بواجهة React وخادم Node.js وExpress 5 منفصلين داخل مستودع واحد، وخادم منظّم إلى وحدات للمجالات المختلفة. نستخدم PostgreSQL واحدة مع Prisma، لأن فريق التطوير صغير والميزانية محدودة، ولتقليل تعقيد تطوير وتشغيل خدمات مستقلة مع إبقاء حدود الوحدات واضحة. تُدار قاعدة البيانات على خادمنا؛ وما زالت آلية عزل بيانات العيادات تحتاج إلى تصميم تفصيلي.
