# تطبيق موحّد منظّم إلى وحدات مع PostgreSQL

نبدأ بتطبيق يخدم عدة عيادات مستقلة، بواجهة React وخادم Node.js وExpress 5 منفصلين داخل مستودع واحد، وخادم منظّم إلى وحدات للمجالات المختلفة. نستخدم PostgreSQL واحدة مع Prisma، لأن فريق التطوير صغير والميزانية محدودة، ولتقليل تعقيد تطوير وتشغيل خدمات مستقلة مع إبقاء حدود الوحدات واضحة. تُدار قاعدة البيانات على خادمنا. عند كتابة القرار كانت آلية العزل التفصيلية قيد التصميم؛ نُفذت لاحقًا للحسابات بقيود العيادة والعلاقات المركبة وفحوص الخادم، وفق `prisma/schema.prisma` و`docs/ui-contract.md`. يستكمل ADR 0002 تنظيم طبقات الخادم دون استبدال هذا القرار.
