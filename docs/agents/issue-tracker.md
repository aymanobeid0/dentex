# Issue tracker: Local Markdown

- تُحفظ كل ميزة في `.scratch/<feature-slug>/`.
- تُحفظ المواصفة في `spec.md`، وكل مهمة تنفيذية في ملف مستقل `issues/<NN>-<slug>.md`.
- يُسجَّل التصنيف في سطر `Status:` قرب بداية ملف المهمة.
- تُضاف التعليقات في نهاية الملف تحت `## Comments`.
- نشر مهمة يعني إنشاء ملفها المحلي؛ وقراءتها تعني فتح المسار المحدد.
- يستخدم wayfinder الملف `map.md` وملفات المهام مع حقول النوع والحالة والاعتماديات لتحديد المهمة المتاحة وحجزها وحلها.

## تقدم التنفيذ والتاريخ

`Status` تصنيف التعامل مع المهمة؛ `closed` مهمة أُنجزت واعتمدت أو دُمجت. `Execution` في تذاكر انتقال الحالة يميز not-started وin-progress وcomplete، مع سبب واضح لانتظار المستخدم عنده. الفهرس لقطة مشتقة من هذه الحقول، والأب يتابع المجموع دون إغلاق مبكر.

عند اعتماد الفحص أو الرفع أو الدمج، حدّث الحقول الحالية والفهرس والأب والتسليم في التعديل نفسه. احفظ نتائج الاختبارات ولقطات Git القديمة تحت عنوان تاريخي؛ أضف المتابعة الحديثة بدل استبدال دليل سابق بنتيجة لم تُشغّل حينها. أرقام تذاكر المجال وأرقام انتقال حالته مساحتان مختلفتان؛ استخدم المسار في الإحالات.
