# قاعدة التطوير المحلية وتسليم العمل

## الحالة

قاعدة PostgreSQL محلية تعمل عبر Docker Compose. في 1 نوفمبر 2026 طُوبق سجل Prisma الأساسي وترحيل الصلاحيات بعد مقارنة المخطط وقيوده. بقيت سجلات العيادة والحسابات والأدوار وإسناداتها مطابقة لحالتها قبل الترحيل، بما فيها تجزئات كلمات المرور وإصدارات الاعتماد. تمثل بيانات العيادة والحسابات إعداد التطوير المحلي وليست بيانات اختبار آلي.

## التشغيل

- تشغيل قاعدة البيانات: `docker compose up -d --wait`.
- الإيقاف مع الحفاظ على البيانات: `docker compose stop`.
- تشغيل التطبيق محليًا بعد تثبيت الاعتماديات: `npm run dev`، ثم افتح `http://127.0.0.1:5173`.
- البيانات محفوظة في volume مستقل. لا تحذف volume لإعادة التشغيل أو التجربة.
- ملف `.env` يحتوي بيانات الاتصال المحلية ومستثنى من Git؛ لا تُطبع محتوياته أو تُنقل إلى المواصفات والتذاكر.
- كلمات مرور الحسابات ليست محفوظة في ملفات المشروع كنص صريح. إعادة تشغيل `node scripts/seed-local.mjs` تتطلب متغيري البيئة `CLINIC_ADMIN_PASSWORD` و`PLATFORM_ADMIN_PASSWORD`، وتتحقق من الحسابات الموجودة دون استبدال كلمات مرورها.

## ملاحظات التنفيذ والمحافظة على البيانات

1. اقرأ AGENTS.md والمواصفة المحلية وعقد الشاشات، والتزم بالتصميم المعتمد في login-preview.html.
2. اعتُمد الترحيل `20261101000000_baseline` للقاعدة القائمة بعد أن أعادت مقارنة Prisma ترحيلًا فارغًا والتحقق من قيود PostgreSQL، ثم طُبق `20261101010000_role_permissions`. لا تستخدم reset على هذه القاعدة؛ طبّق الترحيلات اللاحقة بأمر `npm run db:deploy`.
3. تنسيق تجزئة كلمات المرور: `scrypt$N$r$p$saltHex$keyHex`، حيث N=32768 وr=8 وp=1 وطول المفتاح 64 بايت. ملح scrypt المستخدم هو النص السداسي نفسه (UTF-8)، وليس تحويله إلى بايتات؛ طابقه عند التحقق. استعمل مقارنة ثابتة الزمن.
4. مدير البرنامج في جدول مستقل، ومدير العيادة مربوط بدور admin. طُبقت الصلاحيات المبدئية لدوري dentist وreceptionist؛ يحتفظ دور admin بكامل صلاحيات العيادة في التطبيق.
5. اختبارات التطبيق تستخدم قاعدة `dentex_test` منفصلة وبيانات وهمية؛ لا توجه اختباراتها إلى قاعدة التطوير. إعدادات JWT ومصدر الواجهة محفوظة في `.env` المحلي المستثنى من Git.
6. إعداد قاعدة التطوير لا يعني إغلاق تذاكر التطبيق؛ تُقيّم كل تذكرة وفق تنفيذها واختباراتها والتحقق من واجهتها.
